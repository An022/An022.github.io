# Story illustration assets

The three-scene prototype uses transparent WebP artwork derived from An's approved character sheet. Every character, object, and environment remains a separate layer so future scenes can reuse and reposition the artwork without changing the Story Deck engine.

The approved character sheet is art direction only and must not be displayed as a website asset.

Folders:
- `characters/`: consistent poses of An
- `objects/`: independently animated props
- `environments/`: independently revealed locations
- `decorations/`: routes and annotations
- `references/`: art-direction files only

The older SVG files remain as development fallbacks. Active artwork uses the `.webp` paths in `js/story-data-detour-v40-20260924.js`.
