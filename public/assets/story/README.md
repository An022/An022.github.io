# Story illustration assets

These SVG files are temporary, transparent placeholders for the three-scene Story Deck prototype. Replace a file in place to keep the same story data and layout, or update its path in `js/story-data-detour-v40-20260924.js`.

The approved character sheet is art direction only and must not be displayed as a website asset.

Folders:
- `characters/`: poses of An
- `objects/`: independently animated props
- `environments/`: independently revealed locations
- `decorations/`: routes and annotations
- `references/`: art-direction files only
