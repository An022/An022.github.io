# An Lee - Personal Blog

A Jekyll-based personal blog template.

## Setup

This is a Jekyll blog. To run it locally, you need to have Ruby and Jekyll installed.

1. Install dependencies:
```bash
bundle install
```

2. Start the Jekyll server:
```bash
bundle exec jekyll serve
```

3. Open [http://localhost:4000](http://localhost:4000) to view it in the browser.

## Configuration

Edit `_config.yml` to customize:
- Personal information (name, title, description)
- Social media links
- Blog settings

## Writing Posts

Add new blog posts to the `_posts/` directory following the naming convention:
`YYYY-MM-DD-title.md`

## About

This blog template is based on a clean, minimal design focused on readability and content.
